## 📋 Функциональные модули

### 📝 Модуль экспертного опроса
- Анонимная оценка 3 сценариев по 12 критериям (шкала 1-5)
- Ранжирование сценариев по предпочтительности

- **Интегральные оценки**: Взвешенные оценки сценариев

- 23 конкретных риска по 5 категориям:
  - 💻 Технологические риски (5 рисков)

  - 📈 Рыночные риски (4 риска)
  - 📜 Регуляторные риски (4 риска)
  - 💰 Финансовые риски (5 рисков)
- Матрица "вероятность × влияние"
- Визуализация распределения по уровням критичности

### 👥 Модуль управления экспертами

## 🔬 Научная методология

### Теоретическая база
- **Balanced Scorecard (BSC)**: 4 перспективы оценки (финансовая, клиентская, процессная, развития)
- **Многокритериальный анализ решений (MCDA)**: Структурированный подход к выбору альтернатив
- **Экспертное оценивание**: Метод получения количественных оценок от квалифицированных специалистов

### Математический аппарат
```
Взвешенная интегральная оценка:
I = Σ(wi × xi), где wi — вес критерия, xi — оценка

Коэффициент конкордации Кендалла:
W = 12S / [n²(m³-m)], где S — сумма квадратов отклонений

Критерий значимости χ²:
χ² = n(m-1)W при α = 0.05
```

### Система критериев
- **Финансовая перспектива** (35%): Доходы, расходы, окупаемость, новые источники
- **Клиентская перспектива** (30%): Лояльность, время обслуживания, удовлетворенность
- **Процессная перспектива** (20%): Автоматизация, гибкость, качество данных
- **Перспектива развития** (15%): Компетенции, технологии, инновации
