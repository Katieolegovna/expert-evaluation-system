# 🛩️ Экспертная оценка стратегических сценариев - Аэропорт Шереметьево

[![Demo](https://img.shields.io/badge/Demo-Live-brightgreen?style=for-the-badge&logo=github)](https://katieolegovna.github.io/expert-evaluation-system/)
[![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)](LICENSE)

Веб-приложение для проведения экспертного опроса по оценке стратегических сценариев развития неавиационных услуг Международного аэропорта Шереметьево до 2031 года.

## 🚀 Демо

[Открыть приложение](https://katieolegovna.github.io/expert-evaluation-system/)

## ✨ Возможности

- 📝 **Анонимные анкеты экспертов** с валидацией данных
- 📊 **Автоматический расчет** коэффициента конкордации Кендалла
- 📈 **Визуализация результатов** с диаграммами и графиками
- 🔍 **Анализ чувствительности** по перспективам BSC
- 👥 **База экспертов** с детальным просмотром
- 🌓 **Темная и светлая темы**
- 🌐 **Русский и английский языки**

## 🛠️ Технологии

- HTML5
- CSS3  
- Vanilla JavaScript
- Без внешних зависимостей

## 📋 Функциональность

### 📝 Анкета эксперта
- Анонимная оценка 3 сценариев по 12 критериям
- Ранжирование сценариев
- Валидация данных

### 📊 Результаты анализа
- Весовые коэффициенты критериев
- Взвешенные интегральные оценки
- Коэффициент конкордации Кендалла с формулами
- Проверка значимости по критерию χ² Пирсона
- Анализ чувствительности
- Предварительные выводы

### 👥 База экспертов
- Список всех экспертов
- Детальный просмотр анкет
- Фильтрация по параметрам

## 🚀 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/username/sheremetyevo-expert-system.git

# Перейти в папку проекта
cd sheremetyevo-expert-system

# Запустить локальный сервер
python -m http.server 8000

# Открыть в браузере
# http://localhost:8000
```

## 📝 Использование

1. 🌐 Откройте [демо приложения](https://katieolegovna.github.io/expert-evaluation-system/) в браузере
2. 📋 Заполните анкету эксперта или просмотрите сгенерированные данные  
3. 📊 Перейдите на вкладку "Результаты анализа"
4. 🔍 Изучите статистические показатели и выводы
