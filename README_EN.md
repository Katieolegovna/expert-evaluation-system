# Expert Evaluation System for Strategic Scenarios

Web application for conducting expert analysis of strategic scenarios for airport non-aviation services development using Kendall's method and Balanced Scorecard (BSC).

## 🚀 Demo

[Open Application](https://katieolegovna.github.io/expert-evaluation-system/)

## ✨ Features

- 📝 Anonymous expert survey forms
- 📊 Automatic Kendall's concordance coefficient calculation
- 📈 Results visualization with charts and diagrams
- 🔍 Sensitivity analysis by BSC perspectives
- 👥 Expert database with detailed view
- 🌓 Dark and light themes
- 🌐 Russian and English languages

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- No external dependencies

## 📋 Functionality

### Expert Survey
- Anonymous evaluation of 3 scenarios by 12 criteria
- Scenario ranking
- Data validation

### Analysis Results
- Criteria weight coefficients
- Weighted integral scores
- Kendall's concordance coefficient with formulas
- Significance test by χ² Pearson
- Sensitivity analysis
- Preliminary conclusions

### Expert Database
- List of all experts
- Detailed survey view
- Parameter filtering

## 🚀 Installation

```bash
# Clone repository
git clone https://github.com/Katieolegovna/expert-evaluation-system.git

# Open index.html in browser
```

## 📝 Usage

1. Open `index.html` in browser
2. Fill expert survey or view generated data
3. Go to "Analysis Results" tab
4. Study statistical indicators and conclusions
